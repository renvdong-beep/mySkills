# Shell 脚本调试与加固

对 shell 脚本进行调试、错误处理加固和最佳实践检查。

## 触发条件
- 用户提到"脚本报错"、"调试"、"脚本有问题"
- 修改或新增 shell 脚本时
- 需要增强脚本的健壮性

## 执行步骤

1. **定位错误**
   - 在脚本开头临时加 `set -x` 开启调试输出
   - 或用 `bash -x script.sh` 运行
   - 关注变量展开结果和命令执行顺序

2. **错误处理加固**
   - `set -e`：命令失败立即退出（注意：管道命令只检查最后一个，需用 `set -o pipefail`）
   - `set -u`：引用未定义变量时报错
   - `set -o pipefail`：管道中任一命令失败则整个管道失败
   - 推荐组合：`set -euo pipefail`

3. **常见问题检查**
   - 变量是否用双引号包裹（防止空格/空值问题）
   - `rm -rf` 路径变量是否可能为空
   - `cd` 是否可能失败导致后续命令在错误目录执行
   - 子 shell 和管道中的变量修改是否生效
   - 函数返回值是否被正确检查

4. **验证修复**
   - 去掉 `set -x`（或保留到稳定后再去掉）
   - 用正常参数和边界情况分别测试
   - 确认错误信息清晰可读

## 注意事项
- `set -e` 对 `if`/`while`/`||`/`&&` 中的命令不生效，这是预期行为
- 某些命令预期会失败（如 `grep` 无匹配），需要用 `|| true` 显式忽略
- 加固是渐进的，不要一次性加太多 strict 选项导致脚本大面积报错
