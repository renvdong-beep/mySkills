# 内外网代码合并同步

外网开发环境与内网 git 仓库代码需要同步时，安全地合并差异化改动。

## 触发条件
- 用户需要将外网开发的代码同步到内网 git
- 两个环境有差异化配置（IP、路径等）
- 用户提到"内网"、"外网"、"同步"、"合并"

## 执行步骤

1. **对比两个目录**
   ```bash
   diff -rq <外网目录> <内网目录> \
     --exclude=.git --exclude=__pycache__ \
     --exclude='*.log' --exclude='*.swp'
   ```
   根据项目实际情况增减 `--exclude` 项。

2. **逐文件分析差异性质**
   - **环境差异**：IP地址、域名、路径等，这类差异保留目标环境版本
   - **功能差异**：新增函数、新增逻辑，这类需要合并到目标环境
   - **版本差异**：版本号不同，与用户确认使用哪个版本
   - **临时文件**：临时配置、测试文件等，不需要合并

3. **确定合并策略**
   - 基于目标环境版本为基础
   - 只覆盖源环境的功能改动文件
   - 环境配置文件不覆盖
   - 整个新增目录直接拷贝

4. **执行合并**
   ```bash
   # 单文件覆盖
   cp <源>/file <目标>/file
   # 整目录拷贝
   cp -rf <源>/new_dir <目标>/new_dir
   ```

5. **验证**
   - 在目标目录检查 git status 确认改动范围
   - 在目标目录执行构建/打包验证

## 注意事项
- 配置文件中的环境相关值（IP、域名、路径）是环境差异，不要覆盖
- 版本文件需与用户确认使用哪个版本号
- 临时/测试配置文件不需要合并
- 合并前确认目标 git 的分支状态
- 不同项目的环境差异类型不同，需根据实际 diff 内容判断
