# 构建脚本差异分析

对比两个版本的构建脚本，分类识别差异来源。

## 触发条件
- 用户需要对比构建脚本的不同版本
- 用户提到"差异"、"对比"、"其他开发者改动"

## 执行步骤

1. **执行 diff 对比**
   ```bash
   diff <当前版本> <对比版本>
   ```

2. **差异分类**
   将每处差异归入以下类别：
   - **自己的功能改动**：如新增函数、新增变量、修复逻辑
   - **他人的兼容性更新**：其他开发者新增的改动
   - **环境配置差异**：IP、路径等环境相关差异

3. **输出分类报告**
   - 列出每处差异的行号、内容摘要
   - 标注差异类别
   - 标注是否有遗漏的他人改动需要合并

4. **合并建议**
   - 如果有他人改动需要合并，给出具体合并步骤
   - 如果全部是自己的改动，明确告知无需额外合并

## 注意事项
- diff 输出中 `<` 是当前版本，`>` 是对比版本
- 关注删除行（d）和新增行（a），不仅是修改行（c）
- 函数级别的差异要完整分析，不要只看行号
- 不同项目的构建工具不同（Makefile、CMake、shell 脚本等），分析方法相同
